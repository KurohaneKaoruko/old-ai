# 1990s Rule-Based Machine Translation (Simplified)

This subproject implements a toy rule-based MT pipeline (EN -> ZH) with:

- dictionary lookup
- phrase rewrite rules
- token-level fallback

## What It Demonstrates

- symbolic transfer-based translation
- handcrafted rules and lexical mappings
- deterministic output without learning

## Files

- `rbmt.js`: translator
- `demo.js`: sample translations

## Run

```powershell
node language_systems\1990s_rule_based_mt\demo.js
```
