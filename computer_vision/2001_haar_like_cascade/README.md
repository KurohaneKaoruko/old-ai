# 2001 Haar-like Cascade Detector (Toy)

This subproject implements a toy cascade detector inspired by Viola-Jones
style stage filtering.

## What It Demonstrates

- handcrafted Haar-like features
- staged rejection cascade
- fast early exits for negatives

## Files

- `cascade.js`: staged threshold detector
- `demo.js`: toy window feature classification

## Run

```powershell
node computer_vision\2001_haar_like_cascade\demo.js
```
