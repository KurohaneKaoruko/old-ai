# 1986 Subsumption Architecture (Simplified)

This subproject implements a behavior-based control loop inspired by
Brooks-style subsumption architecture.

## What It Demonstrates

- layered reactive behaviors
- higher-priority layers suppress lower-priority actions
- no explicit world model planning

## Files

- `subsumption.js`: behavior layers and arbitration
- `demo.js`: toy mobile-robot loop

## Run

```powershell
node robotics_systems\1986_subsumption_architecture\demo.js
```
