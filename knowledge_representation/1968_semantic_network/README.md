# 1968 Semantic Network (Simplified)

This subproject implements a classic semantic network with:

- `is_a` inheritance
- inherited abilities (`can`)
- exception handling (`cannot`)

## What It Demonstrates

- symbolic knowledge graph style reasoning
- hierarchy-based inheritance
- explicit exception rules

## Files

- `semantic_network.js`: network + inference logic
- `demo.js`: runnable example

## Run

```powershell
node knowledge_representation\1968_semantic_network\demo.js
```
