# 1974 Frame-Based Representation (Simplified)

This subproject implements a frame system with inheritance and default slots.

## What It Demonstrates

- concept/object frames
- slot inheritance through parent frames
- default values and local overrides

## Files

- `frames.js`: frame data model and lookup logic
- `demo.js`: inheritance/override example

## Run

```powershell
node knowledge_representation\1974_frames\demo.js
```
