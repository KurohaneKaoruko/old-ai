# 1956 Logic Theorist (Simplified)

This subproject implements a small symbolic theorem prover inspired by the
Logic Theorist era: rule-based reasoning over explicit symbolic statements.

## What It Demonstrates

- backward-chaining proof search
- rule application using explicit premises and conclusions
- proof tree output

## Files

- `logic_theorist.js`: core prover
- `demo.js`: runnable example

## Run

```powershell
node symbolic_reasoning\1956_logic_theorist\demo.js
```

## Notes

This is intentionally minimal and educational:

- no full first-order unification
- statements are treated as exact symbols (strings)
