# 1990s HMM POS Tagger (Simplified)

This subproject implements a Hidden Markov Model (HMM) tagger using Viterbi
decoding.

## What It Demonstrates

- probabilistic sequence modeling
- transition and emission probabilities
- dynamic programming decoding

## Files

- `hmm_tagger.js`: HMM tagger with Viterbi
- `demo.js`: part-of-speech tagging example

## Run

```powershell
node statistical_nlp\1990s_hmm_tagger\demo.js
```
