# 1977 Script-Based NLU (Simplified)

This subproject implements a script-based understanding approach inspired by
Schank-style scripts: map events to stereotyped scenario steps and infer
missing expected steps.

## What It Demonstrates

- template/script-based narrative interpretation
- event normalization
- missing-step inference in a known scenario

## Files

- `script_nlu.js`: script model and inference
- `demo.js`: restaurant-story example

## Run

```powershell
node conversational_agents\1977_script_nlu\demo.js
```
