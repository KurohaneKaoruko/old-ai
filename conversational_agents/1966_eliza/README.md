# 1966 ELIZA (Simplified)

This subproject implements a compact ELIZA-style chatbot using
keyword/pattern matching and template responses.

## What It Demonstrates

- pattern-based conversation (no real understanding)
- pronoun reflection (`I` -> `you`, `my` -> `your`, etc.)
- deterministic response templates

## Files

- `eliza.js`: chatbot logic
- `demo.js`: interactive terminal chat

## Run

```powershell
node conversational_agents\1966_eliza\demo.js
```

Type `quit` to exit.
