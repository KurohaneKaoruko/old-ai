# 1980s Blackboard System (Simplified)

This subproject implements a blackboard architecture where multiple knowledge
sources iteratively add and refine hypotheses on a shared board.

## What It Demonstrates

- shared blackboard data structure
- knowledge sources operating in turns
- hypothesis aggregation and ranking

## Files

- `blackboard.js`: board + knowledge source engine
- `demo.js`: toy visual-symbol recognition example

## Run

```powershell
node expert_systems\1980s_blackboard_system\demo.js
```
