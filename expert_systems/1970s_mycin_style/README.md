# 1970s MYCIN-Style Expert System

This subproject implements a small expert-system inference engine inspired by
MYCIN-style certainty factors (CF).

## What It Demonstrates

- rule-based forward chaining
- uncertain evidence handling
- certainty factor combination

## Files

- `mycin_like.js`: inference engine
- `demo.js`: diagnosis-style example

## Run

```powershell
node expert_systems\1970s_mycin_style\demo.js
```
